# Как собраны кадры фасада (8 октября 2026)

Исходники: `../photo_1_...jpg` (горит, 16:9), `A.jpg` (погашен, 16:9), `B.jpg` (горит, вертикаль), `C.jpg` (погашен, вертикаль). A, B, C сгенерированы заказчиком по промптам из `статус.md`.

1. Совмещение. `align.js` / `strips.js` ищут сдвиг по контурам.
   - A = photo_1 со срезом 3 строк сверху и полпикселя сдвига: горящий = `crop=1280:714:0:3`, погашенный = `remap.js A.jpg … "0:-0.5,714:-0.5"`.
   - C плавно съезжает книзу: `remap.js C.jpg … 714 1280 "0:0,200:-0.25,420:-0.5,544:-0.75,620:-1.4,736:-1.75,930:-1.9,1100:-2.4,1280:-2.5"`.
2. `fix.js` — подпись под سافا в C заменена подписью из B (затемнённой), снята синева экрана в зале A.
3. `build.js d|m` — маски зон из разницы «горит минус погашено» (после выравнивания общей яркости) внутри прямоугольников зон.
4. Сжатие в WebP: горящий 16:9 q80, погашенный 16:9 q72, горящий вертикальный q72, погашенный вертикальный q66; маски — 2/3 размера, без потерь.

Скрипты ждут промежуточные файлы (`lit_d.png`, `off_d.png`, `lit_m.jpg`, `off_m.png`) рядом с собой. Нужны node и ffmpeg.
